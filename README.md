# swift-rfc-7235

> **Status: Namespace-reservation** — This package reserves the RFC 7235 namespace. RFC 7235 (HTTP/1.1 Authentication) was obsoleted by RFC 9110; its authentication semantics are consolidated into HTTP Semantics/Caching and implemented in swift-rfc-9110. The package currently exposes only an empty `RFC_7235` namespace enum and is not independently implemented.
